## 快速開始（Docker 上線）

### 前置準備
1. **Docker Desktop** 已安裝
2. **金融廳 EDINET API key**（免費申請，[點此申請](https://disclosure2.edinet-fsa.go.jp/weee0020.aspx)）

### 上線步驟

#### 1. 重新 build Docker image（包含最新改動）
```bash
cd CapyStock
docker-compose build --no-cache
```

#### 2. 建立設定檔 `data/.env`
在 `data/` 目錄下建立 `.env` 檔案，寫入：
```
EDINET_API_KEY=<你的_API_key>
```

#### 3. 啟動服務
```bash
docker-compose up -d
```

#### 4. 驗證啟動成功
打開瀏覽器，訪問：
```
http://localhost:8000
```

應該看到 **CapyStock Dashboard**，右上角有 4 個分頁：
- 📊 **投機** — 進出場訊號監控
- 🍗 **金雞** — 高股息好公司篩選  
- 🔬 **模擬** — 回測與參數最佳化
- ⚙️ **資料** — 行情更新 & 手動上傳

## 核心概念 — 舅舅心法映射

### 你不需要成為工程師
CapyStock 把舅舅的 13 篇籌碼心法**自動化**成系統警告。  
你只需要：
1. **每天看儀表板** → 找出系統標記的警告股
2. **依照檢查清單** → 判斷是洗盤還是倒貨
3. **人工決策** → 最終買賣決定仍由你決定

### 舅舅心法 ↔ CapyStock 映射

| 舅舅心法 | 系統如何實現 | 你在 CapyStock 看到 | 
|---------|----------|----------------|
| **第一盤：連續性濾網**（分點連續 3 天買超） | 外資/法人連續 5 日買超 | 投機頁面的 「吃貨訊號」綠卡片（強度分級） |
| **第二盤：成本濾網**（現價不超主力成本 5%） | 追蹤起始價為「成本錨」；自動計算預期停損位 | /watchlist 頁面的「停損價」欄位 |
| **第三盤：戶數濾網**（籌碼集中） | 信用残下降 + 外資買超同步 = 籌碼集中 | 投機頁面卡片的 「戶數濾網✓」徽章 |
| **進場時機**（不追高，在成本附近等） | 自動計算「最後一階成本帶」 | /watchlist 頁面 → 編輯時填入 `master_cost` / `last_step_price` |
| **抱單 4 條件**（3 選 2 出場） | 監控法人賣超、信用残暴增、股價跌破月線 | 投機頁面的 「出場警告」（紅色/黃色） |
| **停損三條件**（價格、時間、量能） | 自動檢測股價跌破停損線、爆量不漲 | 投機頁面的 「⚠️ 停損」標籤 + 儀表板右上角紅色警示 |
| **主力成本階梯**（每階的買進均價） | 手動填寫 `last_step_price`；系統用來判斷是否真破底 | /watchlist 頁面 → 編輯 |
| **風報比**（目標價 / 停損距離 ≥ 1:3） | 計算 RR ratio = (目標價 - 進場) / (進場 - 停損) | /watchlist 頁面 → 編輯時自動顯示 RR 數值 |
| **紀律三鐵則**（寫下來、照著做、做完就忘） | 系統自動記錄每一次警告、出場、停損事件 | 點擊任何卡片 → 查看「警告歷史」+「根據」 |

### 📊 投機板塊 — 進出場訊號監控

**場景**：你想追蹤一檔主力正在吃貨的股票。

#### 進入途徑
1. Dashboard 或左上角分頁 → **投機**
2. 或直接在搜尋框輸入股票代號（e.g. `7203` 裕日汽）

#### 你會看到什麼

**列表檢視**（預設）：
- **代號 + 名稱** — 股票識別
- **現價** — 今日收盤價
- **強度** — 「吃貨訊號」的綠色星級（1–5 ⭐，5 星最強）
  - 綠色 ⭐⭐⭐⭐⭐ = 外資連續 5 日買超 + 信用残下降 = 極強信號
  - 綠色 ⭐⭐ = 信號較弱，觀望中
- **警告標籤** 
  - 🟢 吃貨訊號 — 主力在默默建倉
  - 🟡 成本警告 — 現價已接近主力成本（漲幅 >5%），宜等回檔
  - 🔴 出場警告 — 符合「3 選 2 出場條件」，準備脫身或減碼
  - ⚠️ 停損 — 跌破成本 5% 連 2 日，應立刻停損

**點擊任何股票卡片** → 進入「單股深度分析頁」

---

#### 單股深度分析頁（/signals/[code]）

**場景**：你看到一檔股票的「吃貨訊號」5 星，想了解它為什麼是強信號。

**你會看到**：

##### A. 信號卡片區塊（上方）
- **訊號強度卡片**
  - 「吃貨訊號」：列出具體數據
    - 外資過去 5 日買超張數
    - 信用残近 4 週趨勢（↓ 下降 = 籌碼集中）
    - 評語：「極強吃貨訊號」或「信號衰弱」
  
- **警告卡片**（如果有的話）
  - 出場條件 1：法人連 3 日賣超（且 ≥ 過去 10 日買超的 20%）
  - 出場條件 2：信用残連 3 週暴增（且漲幅 > 過去 8 週均 2 倍）
  - 出場條件 3：股價離近 30 日低點漲幅 >30%
  - 停損觸發：股價跌破成本 5% 連 2 日

##### B. 技術指標區塊（中方）
- **K 線圖**（20 日）+ 4 條技術線
  - 短期支撐位 / 近月低點
  - 主力成本帶（如果你在 /watchlist 有填入 `master_cost`）
  
- **快速指標查看器**（工具列）
  - RSI（相對強度指數）
    - > 70 = 超買（主力可能要倒貨）
    - < 30 = 超賣（可能是洗盤，可加碼）
  - MACD（動量指數）
    - 金叉（紅線上穿黃線）= 買訊
    - 死叉（紅線下穿黃線）= 賣訊
  - Bollinger Band（布林帶）
    - 貼上軌 = 可能反轉
    - 貼下軌 = 可能反彈

##### C. 分析摘要（下方）
- **法人買賣動向**（最近 10 日）
- **信用残趨勢**（最近 8 週）
- **EDINET 大量保有申報**（最近 3 日，5% rule）
- **警告歷史**（此股票的所有過往警告）

**你可以做什麼**：
1. 點擊「新增到追蹤清單」→ /watchlist 設定成本、停損、目標價
2. 點擊「模擬交易」→ 進入 /simulation 頁面，檢驗這檔股票的歷史成功率
3. 切換技術指標查看器 → 看 RSI、MACD 確認是否還有上漲空間

### 🍗 金雞板塊 — 高股息好公司篩選

**場景**：你不想短線操作，只想找「配息穩定、本益比低、ROE 高」的好公司長抱。

#### 進入途徑
左上角分頁 → **金雞**

#### 你會看到什麼

**列表**：按「基本面評分」排序
- **評分等級**：STRONG（綠）> HEALTHY（黃）> CAUTION（橙）> RISKY（紅）
  - STRONG = 8 項基本面指標全部及格（銷售成長 + 毛利率 + ROE + CF 等）
  - HEALTHY = 大部分指標健康，適合長期持有
  - CAUTION = 有 1–2 項指標警訊（e.g. 現金流衰退）
  - RISKY = 多項指標亮紅燈，迴避

- **每股配息（DPS）** — 年配息金額
- **配息率** — DPS / EPS，越低越好（表示公司有成長空間，不全部拿來配）
- **本益比** — 股價 / EPS，越低越便宜；配合評分看

**點擊任何公司卡片** → 進入「基本面詳情頁」

---

#### 金雞詳情頁（/dividend/[code]）

**你會看到**：

1. **基本面評分卡**
   - 8 大指標逐項列出 ✅ / ❌
   - 「STRONG」表示適合作為核心持股

2. **配息履歷表**（最近 4 季）
   - 每季 EPS、配息、配息率
   - 判斷：是否穩定增長？還是波動？

3. **財務 4 大比率**
   - **ROE**（股東權益報酬率）— > 10% 最好；< 5% 警訊
   - **運營利率** — > 10% 算健康；< 5% 警訊
   - **負債比** — < 60% 最安全；> 80% 警訊
   - **自由現金流** — 能否支撐配息？是否在成長？

4. **對比功能**
   - 選多個金雞公司 → 點「對比」→ 看誰的基本面最強
   - 幫你快速判斷「該買 A 還是 B？」

**你可以做什麼**：
1. 把 STRONG 公司加到「我的最愛」
2. 點「對比」與其他公司比較配息率與評分
3. 根據「配息率 <30%」篩選有成長空間的公司

### 🔬 模擬板塊 — 回測與參數最佳化

**場景**：你想驗證某套「技術指標 + 籌碼訊號」的進出場策略，看它在過去 1 年是否獲利。

#### 進入途徑
左上角分頁 → **模擬**

#### 功能 1：快速回測（新建）

**你會經過 3 個步驟**：

##### 步驟 1：選股 + 資料範圍
- 選擇追蹤清單內的股票（or 手動輸入代號）
- 選擇回測日期範圍（e.g. 最近 3 個月、6 個月、1 年）
- 初始資金（e.g. 100 萬日圓）

##### 步驟 2：進場規則
選擇**一個**主要進場條件（預設有 3 組可選）：
1. **籌碼訊號** — 吃貨訊號 ⭐ 滿 3 星時進場
2. **技術訊號** — RSI < 30（超賣）時進場
3. **混合訊號** — 吃貨訊號 + RSI 雙重確認

##### 步驟 3：出場規則
選擇**一個**主要出場條件：
1. **籌碼出場** — 法人連 3 日賣超時出場
2. **技術出場** — RSI > 70（超買）時出場
3. **價格目標** — 獲利 +10% 或虧損 -5% 時自動出場
4. **混合出場** — 籌碼 OR 技術任一條件成立就出場

#### 回測結果檢視

**報告內容**：
- **總成功率** — 贏的交易次數 / 總交易次數（%）
- **平均勝率** — 每次賺/賠的平均金額
- **最大虧損** — 最慘的一次虧損
- **盈虧比** — （平均獲利）/（平均虧損）≥ 1.5 才算好策略
- **每一筆交易的詳細紀錄** — 進場日、出場日、獲利、原因

**判讀**：
- 成功率 > 50% 且盈虧比 > 1.5 = 值得真實交易
- 成功率 < 30% = 策略失效，需調整
- 策略在 3 個月內有效，但 1 年內變差 = 市場環境改變，停用該策略

---

#### 功能 2：參數掃描（Sweep）

**場景**：上面的「吃貨訊號進場」成功率 52%；你想試試「改成 4 星才進場」或「改成 2 星」，看哪個最好。

**流程**：
1. 點擊「進階 → 參數掃描」
2. 輸入要試驗的參數範圍（e.g. 吃貨星級：2–5 星都試）
3. 點「開始掃描」→ 系統自動回測所有組合
4. 結果顯示為「熱圖」（綠最好、紅最差）+ 排行榜

**實例**：
```
吃貨星級 3 星 + 獲利目標 +10% = 成功率 52%、盈虧比 1.8（第 3 好）
吃貨星級 4 星 + 獲利目標 +8%  = 成功率 48%、盈虧比 2.1（第 1 好！）
吃貨星級 2 星 + 獲利目標 +12% = 成功率 58%、盈虧比 1.2（成功多但獲利差）
```

你就能選「第 1 好」的組合應用到實盤。

### ⚙️ 資料板塊 — 行情更新 & 手動上傳

**場景**：系統預設每天下午 3:30 自動更新日本股市收盤行情。若你想提前更新，或手動上傳自己整理的資料，在這裡操作。

**📖 完整資料導入指南**：  
不知道去哪裡取得「信用残」「法人買賣」等資料？請詳讀 [**《CapyStock 數據導入完整指南》**](DATA_IMPORT_GUIDE.md)，包括：
- 4 類數據的來源地點（Yahoo JP、JPX、金融廳 EDINET）
- 具體操作步驟（含連結）
- 實際範例操作
- 每週例行維護流程

#### 進入途徑
左上角分頁 → **資料**

#### 功能 1：快速狀態檢查

**你看到一個表格**，每一行是一檔追蹤股票，每一列是：
- **代號 + 名稱**
- **現價** — 今日更新的股價
- **更新時間** — 何時爬取的行情
- **年齡標籤**
  - 🟢 綠色 = 今日最新
  - 🟡 黃色 = 1–2 天前
  - 🔴 紅色 = >3 天未更新，建議重新爬取

#### 功能 2：批量更新

**場景**：今天下午想批量抓取所有追蹤股票的最新行情。

**操作**：
1. 點擊「批量更新」按鈕
2. 看到所有追蹤股票的勾選清單（預設全選）
3. 可手動取消某些股票（e.g. 已下市的）
4. 點「執行」→ 系統開始逐一爬取
5. 畫面顯示**即時進度**（已完成 5 / 12 檔）
6. 完成後顯示「✅ 所有股票已更新」

**耗時**：~30 秒（12 檔股票）

#### 功能 3：手動上傳資料

**場景**：你自己整理了信用残週報，想上傳到系統；或你從 Yahoo Finance 下載了股價 CSV，要導入。

**操作**：
1. 點「上傳資料」分頁
2. 點「拖拉 CSV 到此」區域，或點選檔案
3. 系統自動預覽前 5 行，檢查欄位名稱
4. 若欄位識別正確（綠色 ✅），點「確認導入」
5. 若欄位無法識別（紅色 ❌），修改 CSV 欄位名稱後重試

**支援格式**：
- **信用残**：`date,margin_long,margin_short` 或 `week,融資,融券`（系統自動翻譯）
- **股價**：`date,open,high,low,close,volume` 或 `日期,開盤,最高,最低,收盤,成交量`
- **法人買賣**：`date,foreign_net,institution_net`（正值買超、負值賣超）

### 📝 /watchlist — 追蹤清單管理頁

**場景**：你想新增或編輯追蹤的股票、設定停損價、目標價。

#### 進入途徑
任何頁面 → 右上角「⭐ 追蹤清單」（or 左側邊欄）

#### 你會看到什麼

**表格**：每行是一檔追蹤股票

| 欄位 | 意義 | 編輯方式 |
|------|------|---------|
| **代號** | 股票代號（不可編輯） | — |
| **名稱** | 公司名稱（自動填入） | — |
| **現價** | 今日或最新收盤價 | 自動更新 |
| **成本** | 你的實際買進價（或平均成本） | 手動填或自動取當日收盤 |
| **主力成本** | 主力的估計成本帶中點（舅舅心法第四篇） | 手動填（可空） |
| **最後一階** | 主力成本階梯的最後一檔均價（心法第四篇） | 手動填（可空） |
| **停損價** | 若股價跌破此價，應立刻砍倉 | 自動計算（成本 -5%）或手動改 |
| **目標價** | 你的獲利目標 | 手動填 |
| **RR 比** | (目標價 - 成本) / (成本 - 停損價)，≥ 1:3 才進場 | 自動計算 |
| **加入日期** | 開始追蹤的日期 | 自動記錄 |

#### 新增股票

**操作**：
1. 點「➕ 新增」按鈕
2. 輸入股票代號（e.g. `7203`）→ 系統自動查詢名稱
3. 選擇「成本來源」：
   - **自動（今日收盤）** — 直接用今天的收盤價作成本（最常用）
   - **手動輸入** — 自己填入買進價
4. 點「確認」→ 股票加入清單

#### 編輯股票

**場景**：你已持有 7203，但想編輯停損價和目標價。

**操作**：
1. 找到 7203 的列 → 點「編輯」或直接按該欄位
2. 編輯以下欄位（其他自動）：
   - **主力成本** — 根據舅舅心法，估計主力買進的平均價（可空）
   - **最後一階** — 主力最後一批吃貨的均價（可空）；用來判斷「是否真的破底」
   - **停損價** — 預設 = 成本 × (1 - 0.05)；可改為支撐位或其他參考點
   - **目標價** — 你想賣的價格（e.g. 漲 20%）
3. 點「保存」→ RR 比自動重算

#### 刪除股票

**操作**：

## 常見問題

### Q1: 系統說「吃貨訊號 ⭐⭐⭐⭐⭐」，我應該立刻買嗎？

**A**：不應該。5 星只代表「主力在買」，不代表「已經買完、馬上會漲」。

你還需要檢查：
1. **現價 vs 主力成本**：現價是否 ≤ 成本 × 1.05（5%以內）？
   - 若現價已漲 20%，即使信號再強也是「追高」，違反第二濾網 ❌
2. **信用残趨勢**：是否連續下降（籌碼集中）？✅ 
3. **法人動向**：有沒有「法人在賣超」（表示主力在倒貨）？ ❌

三個都符合 → 可以考慮進場。少一個 → 再等等。

---

### Q2: 什麼時候應該「洗盤是正常的，不要砍」？

**洗盤 vs 倒貨三問**：

| 問題 | 洗盤（不砍） | 倒貨（要砍） |
|------|----------|---------|
| **1. 主力還在嗎？** | 分點仍有買超、或賣超幅度 < 買超 20% | 連 3 日賣超，且累計 > 前 10 日買超 20% |
| **2. 散戶爆衝了？** | 戶數穩定不動 | 戶數連 3 週暴增 |
| **3. 大盤崩了？** | 大盤站在月線上 | 大盤跌破月線且站不回 |

**判斷方法**：進入該股的詳細分析頁，系統會直接列出這三個數據。
- 若 3 個全是「洗盤」答案 → 關掉 APP，去睡覺，下週再看
- 若 1 個以上是「倒貨」答案 → 立刻停損或減碼 ≥ 50%

---

### Q3: 我已經持有某檔股票 2 個月了，還沒有到目標價，該怎麼辦？

**檢查清單**：
1. **目標價設定是否合理？**
   - 風報比 ≥ 1:3？（系統的 RR 欄位）
   - 若 RR < 1:3 → 調低目標價或提高停損（重新計算）

2. **有沒有發生「時間停損」？**
   - 進場後 5–7 日仍在成本帶盤整、未突破 → 減碼一半，重新尋找機會
   - 若已超過 1 個月 → 進入詳細頁，檢查法人/外資買賣動向
     - 若已開始賣超 → 停損
     - 若仍在買超 → 等等（主力還在建倉）

3. **自問**：「如果我現在持有 100 萬現金，我會在目前的股價買進嗎？」
   - 答「會」→ 繼續抱
   - 答「不會」→ 該砍

---

### Q4: 我想用系統做長期持股（不想追蹤進出場），怎麼設定？

**切到「金雞」板塊** → 找 STRONG 或 HEALTHY 評級公司 → 加到最愛

金雞板塊專為長期價值投資設計：
- 基本面評分而非籌碼訊號
- 關注配息與 ROE，不看短期波動
- 年配息率 > 3% 且本益比 < 20 的公司

---

### Q5: 系統沒有建議停損（或出場），我是否應該「無限抱」？

**不應該**。系統的警告都是「參考」，最終決定權在你。

**自我檢查**：
- 「做了一週的決定，現在睡不著」→ 先出來冷靜，無論賺賠
- 「已經持有 3 個月，公司基本面變差（e.g. 營收下滑）」→ 停損
- 「系統的 3 濾網全部失效（吃貨訊號消失、信用残暴增、股價崩跌）」→ 停損

舅舅說：「活得夠久才能賺錢，不要硬等最後一分鐘。」

---

### Q6: 怎麼設定 email 通知？每天都有警告會不會很煩？

**進入「設定」頁** → 選擇通知方式：
- **Realtime**：每有新警告立刻寄（若追蹤很多股票會很頻繁）
- **Daily Digest**（推薦）：每天下午 4 點統一寄一封，列出當天所有警告

**警告類型過濾**（可選）：
- ✅ 吃貨訊號（綠）
- ✅ 出場警告（紅）
- ☐ 成本警告（黃，比較常，可關掉）

---

### Q7: 系統要求我填「主力成本」和「最後一階」，但我不知道怎麼估算？

**簡易估算法**（無須完全準確）：

1. **主力成本** = 股票開始出現「吃貨訊號」後 5–10 日的最低點
   - 例：7203 上週開始 5 星吃貨訊號，過去 10 日最低 2430 → 填 2430

2. **最後一階** = 吃貨訊號最強的那一天的收盤價
   - 例：昨天出現 5 星，收盤 2520 → 填 2520
   - 系統用此來判斷「股價跌破 2520 ×95%，是否真的破底」

**不確定時可空著** → 系統會用「成本」自動計算停損。

---

### Q8: 模擬交易回測得 60% 成功率，但實盤只有 30%，為什麼？

**常見原因**：
1. **時差** — 回測用「當日收盤價」判斷，實盤用「實時價」進出，易滑點
2. **滑價** — 實際掛單時價格已變，填補不到模擬的「完美價格」
3. **情緒** — 實盤看著虧損，容易提前砍倉；回測則機械執行
4. **數據延遲** — 信用残、EDINET 申報都晚 1–3 天，實盤無法即時反應

**改善方法**：
- 模擬結果 -20% = 更接近實盤期望
- 找出「最穩定的 3–5 檔股票」單獨回測，成功率通常更高
- 參數掃描時，優先選「成功率 >45% 且盈虧比 >1.5」的組合

### Q9: 我想導入自己整理的信用残數據，格式怎麼寫？

**進入「資料」→「上傳」** → 拖拉 CSV

**必需欄位**（任意一個即可，系統自動識別）：
```csv
date,margin_long,margin_short,ratio
2026-05-10,18200,4100,4.44
2026-05-17,19100,3900,4.90
```

或：
```csv
week,融資,融券
2026-05-10,18200,4100
2026-05-17,19100,3900
```

系統會自動轉換單位（若你的資料用「股」而非「千股」）。
