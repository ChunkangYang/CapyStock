# 三盤口袋名單 — 使用說明

對應頁面：`http://localhost:8000/pocket`
對應心法：舅舅心法第二篇「每日 10 分鐘三盤濾網選股」（日本市場對映）

---

## 一、這頁在做什麼

每天對全市場跑「三盤濾網」，三關全過的股票才進「口袋名單」：

| 盤 | 心法原意 | 日本對映（本工具） |
|---|---|---|
| 第一盤 連續性 | 同一券商分點連續買超 | 同一 EDINET 申報人在窗口內重複申報（5% rule） |
| 第二盤 成本 | 現價 ≤ 主力成本 +5% | 主力成本＝申報日鄰近收盤均價，現價 ≤ +5% |
| 第三盤 籌碼集中 | 集保戶數連續減少 | 信用残（融資）連續下降 |

---

## 二、日常操作

| 情況 | 操作 |
|---|---|
| 想看今天名單 | 開 `/pocket`，直接看（資料每天自動更新，不必按重新掃描） |
| 不等明早、現在就抓最新申報 | 排程頁按 `edinet_daily_backfill` →「立即執行」，或 `POST /api/v1/scheduler/jobs/edinet_daily_backfill/run` |
| 把某檔加入追蹤 | 該列「＋ 追蹤」按鈕（會帶入主力成本，停損自動錨定主力成本） |
| 用某檔開模擬交易 | 該列「模擬交易」按鈕（跳到 `/simulation/new`，帶入代碼） |

> 每天 05:30 (JST) 排程自動回補 EDINET 申報 + 重算名單，平時不用手動。

---

## 三、欄位怎麼看

- **① 主力申報人 / 次數**：窗口內申報次數最多的申報人＋次數。次數越多＝建倉越積極。
- **② 主力成本**：該申報人各次申報日鄰近收盤的均價（近似主力成本帶）。
- **現價**：最新收盤。
- **溢價 = (現價 − 主力成本) / 主力成本**：
  | 顏色 | 數值 | 意義 |
  |---|---|---|
  | 🟢 綠 | 負數 | 現價**低於**主力成本＝比主力還便宜，最理想 |
  | ⚪ 灰 | 0 | 現價**等於**主力成本 |
  | 🟠 橙 | 正數 | 現價**高於**主力成本＝偏貴；口袋名單只收 ≤ +5%（未到追高） |

  心法：等股價回檔到主力成本附近（溢價 0~+5%）再進場，不追高。負溢價代表現在就在主力成本之下。

- **③ 融資趨勢**：信用残（融資餘額）N 週的下降幅度，越大代表浮額釋出、籌碼越集中。

---

## 四、漏斗怎麼看

由上到下數字遞減：候選池（有 EDINET 申報）→ 過第一盤 → 過第一+二盤 → 三關全過（口袋名單）。
反映「全市場篩到最後剩幾檔」。下方另有「差一關觀察名單」（過 2 盤）。

---

## 五、名單空了怎麼辦

1. 先看排程執行紀錄：`GET /api/v1/scheduler/runs`，找 `edinet_daily_backfill` 最近一次是否失敗。
2. 常見原因：EDINET API key 過期 / 限流。修好 key 後手動「立即執行」一次即可。
3. 空掃描已有防呆：`candidates=0` 不會覆寫既有好名單（會存成 `_rejected_pocket_*.json`），所以不會再被一鍵清空。

## 六、想調濾網鬆緊

參數在 `capystock/config.py`：

| 參數 | 預設 | 意義 |
|---|---|---|
| `POCKET_GATE1_MIN_FILINGS` | 2 | 第一盤：同一申報人最少申報次數 |
| `POCKET_GATE1_WINDOW_DAYS` | 60 | 第一盤：回看窗口（日） |
| `POCKET_GATE2_COST_TOLERANCE_PCT` | 0.05 | 第二盤：現價最多高於主力成本幾 % |
| `POCKET_GATE3_MARGIN_DECLINE_WEEKS` | 3 | 第三盤：融資連續下降週數 |
